# smart-budget-ph

Interactive **PINoyHub Smart Budget** module built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser.

## Features

- Onboarding with income frequency to monthly conversion
- Giving / Tithes & Offering (toggle, percentage, fixed amount)
- Recurring essential expenses CRUD
- Transaction CRUD with search and period filters
- Income, bills, goals, and reminders CRUD
- Smart budget calculations, progress bars, weekly spending chart, and category breakdown
- Affordability checker and smart insights
- Responsive layout with mobile bottom navigation
- Local storage persistence (mock/local data architecture ready for backend integration)
